# QtCalculator
A GUI-based calculator application built with PySide6.

## Features
The `qtcalculator` repository provides a GUI-based calculator application that can perform basic arithmetic operations. The calculator is designed to be user-friendly, allowing users to input mathematical expressions and receive accurate results.

## Tech Stack
* Python 3.x
* PySide6

## Installation and Getting Started
To use the QtCalculator, follow these steps:
1. Clone the repository: `git clone https://github.com/your-username/qtcalculator.git`
2. Run the application using the command-line interface: `python main.py`

That's it! You should now be able to use the QtCalculator.
